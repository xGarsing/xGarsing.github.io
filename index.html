HumanOS Note

HumanOS Note — личное приложение для заметок и проектов под macOS и Android. Все записи хранятся в зашифрованном хранилище на устройстве пользователя.

По желанию пользователь может подключить свой аккаунт Google, чтобы приложение синхронизировало зашифрованную копию данных между его устройствами через Google Drive. Подробности — в политике конфиденциальности.
